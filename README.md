# 🌴 TripMate - Your Ultimate Travel Packing Checklist

TripMate is a sleek, modern, and highly interactive React application designed to make your travel preparations stress-free. Whether you're planning a weekend getaway or a month-long adventure, TripMate helps you organize your essentials, track your packing progress, and ensure nothing gets left behind.

**[🚀 Live Demo]- https://tripmateproject.netlify.app/**

---

## ✨ Features

- **📝 Smart Item Entry**: Add items with custom descriptions and quantities (up to 20).
- **✅ Progress Tracking**: Mark items as packed or unpacked with a single click.
- **🔄 Dynamic Sorting**: Organize your list by:
  - **Input Order**: See items exactly as you added them.
  - **Description**: Sort alphabetically for easy navigation.
  - **Packed Status**: Quickly see what's left to pack.
- **📊 Real-time Stats**: A live "Stats" footer that tells you how many items you have and what percentage is packed.
- **🗑️ Full Management**: Delete individual items or clear the entire list (with a safety confirmation).
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop views.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. **Clone the repo**
   ```sh
   git clone https://github.com/shuaibsiddiqui768/TripMate-Project.git
   ```
2. **Install NPM packages**
   ```sh
   npm install
   ```
3. **Start the development server**
   ```sh
   npm start
   ```

## 🎨 Design Philosophy

TripMate uses a vibrant, high-contrast color palette (warm oranges and deep browns) to create an energetic and inviting user experience. The interface is intentionally minimalist to focus on the task at hand: **getting you ready for your trip.**
